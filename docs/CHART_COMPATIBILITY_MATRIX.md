# Chart compatibility matrix

_Generated by `scripts/make_chart_matrix.py` from the real chart builder (`phase4/data/charts.py`); do not edit by hand. `tests/test_docs_in_sync.py` fails if this file is stale._

Every row below was run against a deterministic synthetic table. **Supported** = a figure was produced. **Message** = the builder refused the combination and returned the quoted user-facing text instead of crashing. Colour/group columns with more than 30 distinct values are refused by design.

## What each chart accepts

| Chart | X | Y | Colour / group | Aggregation |
|---|---|---|---|---|
| Bar Chart | category, date or numeric | numeric (any column with Count) | optional category | yes (category/date X) |
| Line Chart | category, date or numeric | numeric (any column with Count) | optional category | yes (category/date X) |
| Area Chart | category, date or numeric | numeric (any column with Count) | optional category | yes (category/date X) |
| Scatter Plot | any column, different from Y | numeric | optional category | no |
| Histogram | not used | numeric (the column to bin) | optional category | no |
| Box Plot | optional category | numeric | optional category | no |
| Violin Plot | optional category | numeric | optional category | no |
| Pie Chart | category | optional numeric (counts rows if omitted) | not used | yes |
| Donut Chart | category | optional numeric (counts rows if omitted) | not used | yes |
| Heatmap | not used | not used | not used | no (correlation of numeric columns) |

## Aggregation labels

Bar, line, area, pie and donut charts accept `Sum`, `Average` (alias `Mean`), `Median`, `Count`, `Min`, `Max`. Any other label raises a friendly error. `Sum` of a group that is entirely missing stays missing (not 0).

## Edge datasets (covered by `tests/test_charts.py::test_edge_datasets_never_crash`)

Empty table, table with no columns, all-missing Y, constant Y, infinite values in Y, text mixed into a numeric column, high-cardinality X and a single row: every chart type returns either a figure or a message, never an exception.

## Where the full cross-product is tested

`tests/test_charts.py` sweeps chart type x X column x Y column x aggregation x colour column (about 190 test cases, all asserting *figure or friendly message, never an exception*), pins the expected outcome of 26 common combinations, and checks that drawn values equal a pandas groupby, that changing aggregation / colour / chart type changes the figure, and the original bar-chart regression (`region` X with `product` colour).
